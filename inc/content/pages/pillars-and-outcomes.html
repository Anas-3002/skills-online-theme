THE METHOD

Four rules that shape every session

Do the work first

Every module is a deliverable: a merged pull request, a passing test suite, a written decision. Watching is not learning here.

Review is the curriculum

Staff-level judgement is transferred through review comments on your code — the same mechanism that makes engineers grow inside a strong team.

Measure, then fix

Sandbox tests, evaluation harnesses and telemetry make progress visible. When a metric is bad, the next session is about that metric.

Write it down

Every track ends with a written defence of an architectural decision, because that is what senior and staff interviews actually assess.
