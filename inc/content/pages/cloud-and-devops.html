WHAT YOU WILL BUILD

Four systems you can defend in an interview

Each project is reviewed by a working engineer and merged into a repository you own.

cloud

Infrastructure as code

A Terraform module set that stands up a cluster and its baseline services from an empty cloud account, with remote state and review gates.

rocket_launch

A delivery pipeline

Build, test, sign and promote artefacts through staging to production with GitOps reconciliation and a documented rollback.

monitoring

Observability that answers questions

OpenTelemetry traces, service-level indicators, dashboards and burn-rate alerts tied to an error budget.

policy

Guardrails and cost control

Policy checks, namespace quotas, secrets handling and a cost report you can defend to finance.

CURRICULUM

Six modules, in order

Each module ends with reviewed work. Later modules assume the earlier ones are done — that is the point.

Compute, networking, storage and IAM in a real account; the failure modes of each and how to design around them.
Modules, state, workspaces, drift detection and the review workflow that keeps infrastructure changes boring.
Workload primitives, scheduling, resource requests, probes, rollout strategy and the debugging order when a pod will not start.
Pipelines, artefact promotion, progressive delivery, reconciliation and rollback drills.
Instrumentation, cardinality control, dashboards that get read, alert design and error budgets.
Least-privilege access, secret distribution, admission policy and unit economics of the platform you built.
